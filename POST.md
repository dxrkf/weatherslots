# English

When does the forecast fit your plans?

WeatherSlots turns a live Open-Meteo forecast into time windows matching your activity duration, local availability, temperature range, wind limit and hourly rain-probability limit.

Built with Python's standard library. Terminal, JSON and HTML output. No API key for the free non-commercial endpoint. Includes 22 deterministic tests and a real connected demonstration using public Riyadh city-center coordinates.

Hourly forecast matches are not a safety guarantee; check official warnings separately. Provider terms and limits apply.

https://github.com/dxrkf/weatherslots
